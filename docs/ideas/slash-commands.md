# Slash-command ideas

Captured as stubs — details to be filled in later.

Loose inspiration from the YouTube-transcript pipeline
(`other/scripts/youtube-transcripts-mattpocock/`): source-fallback chain,
resumable index, provenance markers, plain-text + structured outputs side by
side.

Each command below has the same skeleton so it's easy to flesh out later:

- **Intent** — one-liner: what problem does it solve.
- **Inputs** — what the user provides / what the command picks up from context.
- **Behaviour sketch** — rough steps.
- **Outputs** — what lands in the workspace / chat.
- **Notes** — open questions, ideas to borrow, links.
